# Iusmorfos — Interoperability Notes

Canonical project:

- https://github.com/adrianlerer/Iusmorfos-dawkins-evolucion

Iusmorfos classifies legal prose by argumentative move:

- normative premise;
- precedential support;
- documentary fact;
- inference;
- strategic recommendation;
- risk characterization.

The purpose in this hub is interoperability: prevent legal drafts from mixing
law, facts, inference and strategy without labeling the transition. The broader
theoretical project remains in the canonical repository.
