# Legal-Memespace — Interoperability Notes

Canonical project:

- https://github.com/adrianlerer/peralta-metamorphosis

Published reference:

- Ignacio A. Lerer, "Computational Detection of Constitutional Drift: Network
  Analysis and Semantic Measurement of Argentine Supreme Court Jurisprudence
  (1922-2025)", Journal of Computational Law and Legal Technology, 2026.
- DOI: https://doi.org/10.47852/bonviewJCLLT62027951

Legal-Memespace is the doctrine-mapping algorithm identified in the JCLLT paper:
principal component analysis for multidimensional doctrine mapping.

In this hub, the local primitive is intentionally small. It classifies legal
prose by argumentative move so downstream systems can keep norm, fact,
precedent, inference, strategy and risk analytically separate. It is not a
replacement for the full Legal-Memespace implementation in the canonical
repository.
